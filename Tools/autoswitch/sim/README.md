# Mixed-text typing simulator

Types a mixed Vietnamese/English corpus into the real engine, key by key, and measures how
often the user still has to switch language by hand.

## Corpora

- `corpus/chat_messages.txt`: 1,869 chat-style messages (21k words), generated with `cargo xtask tool gen-chat`.
- Viblo tech articles (269k words): not committed (third-party content). Recreate with
  `cargo xtask tool fetch-viblo` then `cargo xtask tool clean-viblo`.

## Run

```sh
# From the Rust workspace root:
mkdir -p target
cargo run --release -p sevi-test-tools --bin prep -- Tools/autoswitch/sim/corpus/chat_messages.txt > target/chat.units
cargo run --release -p sevi-test-tools --bin sim -- target/chat.units
cargo run --release -p sevi-test-tools --bin sim -- target/chat.units --lazy
cargo run --release -p sevi-test-tools --bin sim -- target/chat.units --off
```

Existing experiment controls and the Rust tool commands are listed in [Tools](../../README.md).

## Realistic typing

`rtsim units.txt [--seed N] [--show N] [--why KIND] [--only MSG] [--trace]` types each message cleanly and then like a
person (typos fixed with Backspace, Backspace into the last word, cursor ← → trips, clicks, edits earlier in the text,
⌥Z round trips) and checks the engine never changes text from before a cursor move, click or switch. check.sh runs
3 seeds and locks how often a slip still needs the word retyped (`rules/golden/rtsim.json`). See DECISIONS 50-52.

## Corpora in this folder

- `corpus/chat_messages.txt`: 1,869 chat messages (21k words), generated with `corpus/gen_chat.py`.
- `corpus/synthetic_val.txt`: 6,341 lines (87k words) of mixed Vietnamese/English chat, Vietnamese-only and
  English-only text, generated by the Sevi authors with Claude (the validation half of the synthetic sets; the
  test half stays private and unseen). Same license as this repository.

check.sh types both: golden snapshots of the output, ideal-user metrics, and the realistic-typing run.

## Quality scorecard

`cargo xtask tool scorecard [--compare REF]` puts the numbers that describe overall quality in one table, from
public data only: accuracy and manual switches (chat, chat with typos, synthetic), text safety and slip recovery
(realistic typing), auto-correct, speed, locked edge cases, and reported bugs fixed (`rules/reported.tsv`).
CI prints it in the job summary of every push and PR, compared with the engine before the change.
